# Design source (pre-launch)

The artboards in `artboards/` are the Claude Design canvas pages, generated by `generator.py`
(asset keys map to uploaded files through `assets.json`). Until launch, design changes are made
in the generator, republished to the canvas, then rebuilt into `site/` with `tools/build.py`
and `tools/prerender.py`. After launch, edit `site/` directly and retire this folder.
